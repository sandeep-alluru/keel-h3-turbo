# Assets

Brand and media for the README.

| File | What it is |
|---|---|
| `keel-logo.svg` | the wordmark, vector |
| `keel-logo.png` | the wordmark, raster, 1280×320, transparent background |
| `keel-logo-dark.svg` | the wordmark on the dark card, vector |
| `keel-logo-dark.png` | the wordmark on the dark card, raster |
| `keel-mark.png` | the square mark, 512×512, transparent |
| `keel-social-preview.png` | the card a link unfurls into, 1280×640 |
| `hero-poster.png` | the hero still, 1280×704 — the teaser's own geometry, so nothing shifts when the video starts |
| `keel-teaser.mp4` | a 12-second teaser cut from the strongest clip |
| `posters/` | one poster per clip, 1280×720 |
| `posters/demo.png` | the demo's poster — a frame from the demo video at 3 s, 1280×720 |

## How they are made

Everything here is regenerated by one script:

```bash
python3 scripts/make_assets.py --films /path/to/films --clips clips
```

The brand assets need only Pillow and the DejaVu fonts — they are pure geometry, so they render
identically anywhere. The posters and the teaser need `ffmpeg`, and the films to cut from.

The posters are single frames from the real files, cropped to fill 1280×720 and labelled with a
scrim; the hero poster is the exception, cut at the teaser's own 1280×704 so the still a reader
sees before the video starts is the video's own framing. The teaser is 12 seconds of the film that
carries the most movement, cut with:

```bash
ffmpeg -ss 3.5 -t 12.0 -i FILM-BEACON-1920x1056.mp4 \
  -vf "scale=1280:704:force_original_aspect_ratio=decrease,pad=1280:704:(ow-iw)/2:(oh-ih)/2" \
  -c:v libx264 -preset slow -crf 23 -pix_fmt yuv420p -movflags +faststart \
  -c:a aac -b:a 128k assets/keel-teaser.mp4
```

No process screenshots are used here, and no footage that is not a rendered output. Every image
in this directory is cut from a real render.

`posters/demo.png` is the one file the script above leaves out: its source is the demo video,
which is built by `scripts/make_demo.py` rather than cut from a film.
